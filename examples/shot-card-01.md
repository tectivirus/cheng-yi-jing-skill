# 示例：一场戏怎么落成一条提示词

示例只用来说明**顺序与填法**，不是可投喂的成品——真实提示词必须按 §3.7 写满 6000–7000 字符。

## 0. 剧本事实（先锁死，后面不许再变）

| 项 | 值 |
|---|---|
| 集 / 场 | 第 7 集 第 3 场 |
| 人物 | 沈砚（Subject 1）、林晚（Subject 2） |
| 地点 | 老式公寓客厅，午后逆光 |
| 本镜动作 | 林晚把钥匙拍在茶几上，沈砚没有去拿 |
| 台词 | 林晚：「钥匙还你，从此两清。」 |
| 时长 | 8 秒（duration_ms = 8000，来自已确认单镜记录） |
| 参考 | 沈砚定妆图 v3、林晚定妆图 v2、客厅场景图 v1 |

## 1. Shot Card（15 字段，最小回答口径）

| 组 | 字段 | 本镜取值 |
|---|---|---|
| 身份 | subject / asset_version | Subject 1 @ v3、Subject 2 @ v2 |
| 空间 | scene / blocking | 客厅茶几两侧，林晚站、沈砚坐 |
| 时间 | duration_ms / speed | 8000 / 普通对白 5.0 字每秒 |
| 动作 | action_detail | 抬手—落手—停顿三段，接触点=茶几玻璃面 |
| 摄影 | camera_control | 16 键契约：中近景、微推、浅景深 |
| 声音 | dialogue / sfx / ambience | 1 句 9 字、钥匙金属撞击、午后街道底噪 |

八类微节点里，本镜适用且可验证的是：接触、视线、重量、声尾——缺一个就该 HOLD，而不是「差不多就行」。

## 2. 六段式骨架（按顺序填，不加第七段）

```text
subject_definitions
  Subject 1 = 沈砚，绑定 v3 定妆图；Subject 2 = 林晚，绑定 v2 定妆图；
  客厅 = 场景图 v1；S1 = 林晚（按全局首次发声分配，与 Subject 编号无关）。

summary
  [reference generation] 8 秒单镜：林晚把钥匙拍在茶几上，沈砚不接。

retention_analysis
  必须保留：钥匙落桌的金属声、林晚收手后的半秒静止、沈砚视线向下但不伸手。
  不出现 Sx 编号，不复述整段对白。

detailed_description
  350–500 英文词，逐拍写：抬手角度、手腕发力、钥匙落点、玻璃回弹、两人间距不变、
  沈砚眼睑与瞳孔方向、林晚下颌线绷紧、收手轨迹、结尾半秒保持。

overall_soundscape
  逐事件写声景：钥匙撞击（近场、干、无混响）→ 室内底噪（午后街道、远处车流）→
  呼吸与衣料摩擦（只写本镜真实发生的）。

non_diegetic_music
  无配乐；若项目要求，写「无」并说明依据，不自行加情绪垫乐。
```

台词按语言边界写进标签：

```text
<d>[Chinese] 钥匙还你，从此两清。</d>
```

正文其余部分全英文，中文字符只允许出现在 `<d>[Chinese]…</d>` 内。

## 3. 出稿前跑体检器

```bash
python tools/lint_h3_prompt.py prompt.txt
```

PASS 只代表格式与预算过关。接着走 §六：生成前门禁 G0–G20，判定 PASS / HOLD / BLOCKED；
任何 BLOCKED 落在哪一镜就只挂那一镜，不许整集停摆。

## 4. 生成后返修（单主因）

| 现象 | 只动哪个变量 | 禁止连带改 |
|---|---|---|
| 钥匙落点飘 | `detailed_description` 的接触点与落点句 | 身份定义、时长、台词 |
| 沈砚伸手了 | 该拍的行为动词与视线句 | 摄影键、声景 |
| 语速偏快 | `summary` 的时长与台词停顿 | 动作节拍 |

一次只动一个主变量，记 before / after；其余字段禁止漂移，改完重跑体检器。
